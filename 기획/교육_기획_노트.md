# 교육 기획 노트

기존 로드맵(v0.7)의 설계 근거와 편집 기록입니다. 공개 개요와 단원 목차는 [README](../README.md), 수강생의 단계별 성과는 [교육 전후 변화와 단계별 도달 기준](교육_전후_변화와_단계별_도달_기준.md)에서 확인할 수 있습니다.

[Google Docs 원본](https://docs.google.com/document/d/1R_XzbX-ZsIzfXLYIOh0wiJRiKjrUsjCf)

## 기획 원칙

- Andrew Ng의 AI Engineering Skills Map을 전체 구조의 참고 틀로 삼는다.
- 비개발자의 초급부터 중급까지를 대상으로 범위와 깊이를 조정한다.
- 개인의 역량 증강과 업무 개선 경험을 조직 AX를 이끌어갈 초석으로 삼는다.
- 교육 이후에도 스스로 학습하고 발전할 수 있도록 개념 이해와 실무 경험을 함께 쌓는다.

## 문서 구조와 편집 기준

- 본문은 **서론 → 1. LLM Foundation → 2. 데이터 기반 접지 모델 → 3. 에이전틱 시스템 → 4. 평가 주도 개발** 순서로 구성한다.
- 학습 영역은 2단계 제목(`##`), 하위 주제는 3단계 제목(`###`), 세부 묶음은 4단계 제목(`####`)으로 구분한다. 설명과 사례는 해당 주제 아래 목록으로 배치한다.
- 세부 요소와 도달 기준은 편집을 위한 제안이며, 확정된 강의 목록이 아니다.
- 시간, 도구, 실습 과제와 평가 기준은 후속 논의에서 정한다.
- 손글씨의 `Let them`은 판독이 확실하지 않아 임시 표기로 보존한다. 의미를 임의로 확장하지 않는다.
- 악성 코드 이야기는 이해를 돕는 소개용 일화이며, 독립 교육 주제나 제작 실습이 아니다.
- 평가와 개선은 독립된 4단원으로 구성하며, 각 단원의 세부 깊이는 후속 논의에서 정한다.

## 변경 이력

- **2026-11-22:** 공개 개요와 단원 목차를 README에 통합하고 설계 근거와 편집 기록은 이 문서로 분리했다.

- **v0.4 (2026-11-07):** 수정 전 문서를 `교육_커리큘럼_로드맵_초안_v0.4_보관.md`에 보관했다.
